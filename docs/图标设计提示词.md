# 番茄AI · 图标设计提示词套装（Apple / Google 高端简约风）

> 用途：喂给任意 AI 生图工具（Midjourney / DALL·E / 即梦 / 通义万相 / Stable Diffusion 等）
> 覆盖：应用启动图标 ×1 + 底部导航图标 ×5（每个含描边/填充两态）+ 应用内小图标套件 ×1
> 铁律：**所有提示词共享同一"风格基因"后缀**，这是全套风格统一的保障。

---

## 一、全局风格基因（Style DNA）

### 品牌色板（写死在每条提示词里）
| 角色 | 色值 | 用途 |
|---|---|---|
| 品牌强调色 | 番茄红 `#D03050` | 唯一彩色，用于主体或背景 |
| 中性底色 | 浅灰 `#F6F6F7` / 深灰 `#5F5F66` | 图标底、描边 |
| 点缀 | 叶绿 `#2E7D32` | 仅番茄叶 |

### 英文风格后缀（拼在每条提示词末尾）
```
minimalist flat vector icon, Apple SF Symbols and Google Material 3 design style,
rounded geometric shapes, smooth thick rounded strokes, single accent color tomato red #D03050
on soft neutral background #F6F6F7, subtle soft shadow, clean, premium, elegant,
centered composition, generous padding, no text
```

### 中文风格后缀（国内工具用）
```
极简扁平矢量图标，苹果SF Symbols与谷歌Material 3设计风格，圆角几何造型，圆润粗描边，
番茄红#D03050为唯一强调色，浅灰#F6F6F7柔和底色，轻微柔和投影，干净、高级、精致，
居中构图，留白充足，无文字
```

### 通用负面提示词（Negative Prompt）
```
text, letters, words, watermark, photorealistic, 3D render, complex details, cluttered,
rainbow colors, gradient background, harsh shadow, low quality, blurry
```

### 一致性三原则
1. 所有图标使用**同一条风格后缀**，只换主体描述；
2. 工具支持 seed 的话**固定同一个 seed**；
3. 同批生成，从中挑选彼此最协调的（宁可重roll，不要混风格）。

## 五、生成后的使用与集成（交给开发者即可）

| 产物 | 处理方式 |
|---|---|
| 启动图标 1024px | 我来做：拆分为安卓自适应图标（前景 108dp/背景色层）→ 替换 Tauri `icons/` 全套尺寸 → 重新打包 |
| 导航图标 5×2 态 | 我来做：抠底转透明 SVG/PNG → 替换底部导航 emoji → 选中态自动切填充色 → 出新 APK |
| 小图标套件 | 我来做：替换任务行 emoji 按钮 |

**你只需要**：按提示词生成图片 → 把成品图（连同工具名/seed，便于再生成）放进
`D:\program\zcode\tomato-ai\.build\icons-raw\` 文件夹 → 告诉我一声，其余裁切、转码、集成、打包我来。

## 六、挑选时的审美 checklist
- 五个导航图标**视觉重量一致**（笔画粗细相同、占圆比例相同）；
- 主体轮廓在 24px 缩小后仍可辨认（眯眼测试）；
- 全套摆放在一起像"一个家族"（圆角弧度、留白比例一致）；
- 拒绝任何带文字/水印/复杂纹理的产物。
