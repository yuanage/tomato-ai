## 二、安装方法

1. 把 APK 传到手机（见"三、分享方式"），点击 APK 文件；
2. 系统提示"未知来源应用"时：允许安装（小米/华为/OPPO/vivo 各有"安装未知应用"开关，按提示开启一次即可）；
3. 安装完成 → 打开"番茄AI"。

> 说明：测试签名属于自签名，Play 保护机制可能提示"未检测到有害内容"或询问是否安装——属正常现象，选择"仍要安装"。正式上架需改用官方签名（后续可做）。

## 四、功能验证清单（测试用户用）

1. 打开应用 → 专注页正常显示（进度环 + 开始按钮）；
2. 番茄闭环：开始 → 暂停 → 继续 → 放弃 → 完成（完成时应有震动，需开启"完成提醒"开关）；
3. 任务页增删改查、置顶、完成；**关闭应用重开，数据不丢**（IndexedDB 持久化）；
4. 统计页数据与任务同步；
5. AI 助手（默认模拟模式可用；真实调用需在设置页配置 API Key）；
6. 设置页：时长修改生效、**导出错误日志**按钮可用。

## 五、错误日志收集（问题定位用）

- 应用内所有运行时错误自动记录在本地（上限 200 条，含来源/消息/堆栈摘要）；
- 测试中出现异常时：设置 → 数据管理 → **导出错误日志** → 得到 JSON 文件 → 发给开发者；
- 日志只存本机，不含 API Key。

## 六、设备适配说明

| 项目 | 配置 |
|---|---|
| 系统版本 | Android 7.0（API 24）及以上，targetSdk 34（Android 14） |
| 屏幕适配 | 前端按 480px 手机壳自适应 + 安全区适配（刘海屏/手势条）；WebView 随屏幕尺寸自适应 |
| 横竖屏 | 竖屏优先（configChanges 已处理旋转，不重启页面） |
| 中文/字体 | Roboto + Noto Sans SC（离线回退系统字体） |

## 七、已知限制（测试时注意）

1. **锁屏/后台计时暂停**：手机锁屏后 WebView 定时器被挂起，回到前台时间自动校准、记录不丢，但"完成提醒"会延迟到回前台才触发；
2. **浏览器通知不可用**：WebView 不支持系统通知，完成时以震动+提示音提醒（声音在非静音模式可听到）；
3. 首次打开若加载缓慢，属 WebView 初始化正常现象。
