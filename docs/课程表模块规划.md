# 番茄课表（暂定名）· 独立课程表模块规划方案

> 版本：规划 v1.0（待审核）
> 定位：模仿 WakeUp 课程表的使用价值，**根治其"登录繁琐、广告过多"两大痛点**，
> 延续番茄AI的产品哲学：零登录、零广告、零社交、本地优先、极简护眼。

---

## 一、背景与定位

### 1.1 痛点对照（为什么用户会想换掉 WakeUp）
| WakeUp 课程表痛点 | 本产品方案 |
|---|---|
| 需要注册/登录账号，数据上云 | **零登录**：无账号体系，数据默认仅存本机 |
| 广告多（开屏/信息流/会员引导） | **零广告零会员**：无任何商业化模块 |
| 导入教务需登录校园系统，隐私外泄风险 | 手动录入 + 本地 JSON 备份/恢复（自决数据） |
| 功能堆叠、社区内容噪音 | 只做"看课表 + 管课程"两件事，极简 |

### 1.2 工程形态（待确认，二选一）
- **方案 A（建议）独立工程**：新目录 `D:\program\zcode\tomato-class`，复用番茄AI 已验证的
  Tauri 安卓工具链（.build）、持久化双写加固方案（代码移植裁剪）、图标风格与打包流水线；
- 方案 B：番茄AI 内新增"课程表"Tab——不满足"独立运行"要求，仅作备选。

### 1.3 命名
暂用「番茄课表」。正式名可后定（不影响开发）。

## 二、核心功能模块划分（基础版 = P0 + P1）

| 模块 | 内容 | 归属 |
|---|---|---|
| M1 周课表视图 | 7 天 × 节次的网格课表；课程卡片色块展示；今天高亮；左右滑动或点击切周 | P0 |
| M2 课程管理 | 添加/编辑/删除课程；表单含名称、地点、教师、星期、起止节次、周次规则、颜色 | P0 |
| M3 本地持久化 | 移植双写方案（IndexedDB + 文件镜像 + 写队列 + 启动预热）；键：courses / schedule_meta / settings | P0 |
| M4 周次与日期逻辑 | 学期第 N 周计算（学期起始日期设置）；**单周/双周/自定义周次**过滤显示；当前周自动定位 | P1 |
| M5 节次时间表 | 编辑一天节次的时间段（上午/下午/晚上），课表行高按真实时间比例（可选） | P1 |
| M6 数据备份 | 全量 JSON 导出/导入（无账号下的数据迁移通道） | P2 |
| M7 外观与细节 | 暗色主题、课程颜色盘、空状态引导、安全区适配、动效（reduced-motion 感知） | P1~P2 |

**明确不做（对齐极简原则）**：账号/云同步、社区/社交、成绩/教务导入、广告/会员、
推送广告、复杂日历联动（仅保留"跳转系统日历"可选，P3）。

## 三、数据结构设计

### 3.1 课程 course
```js
{
  id: 'uuid',
  name: '高等数学',            // 必填
  location: 'A-101',           // 选填
  teacher: '王老师',           // 选填
  dayOfWeek: 1,                // 1=周一 … 7=周日
  startSection: 1,             // 起始节次（1 起）
  endSection: 2,               // 结束节次（含）
  weekRule: { type: 'every' | 'odd' | 'even' | 'custom', weeks: [3,5,9] }, // 周次规则
  color: '#D03050',            // 卡片色（预置色盘，也可自动分配）
  note: '',                    // 备注
  createdAt: 1735000000000
}
```

### 3.2 学期/周次元数据 schedule_meta
```js
{
  semesterStart: '2026-09-07', // 学期起始周一（第 1 周锚点）
  totalWeeks: 20,              // 本学期周数（显示用）
  sections: [                  // 节次时间表（M5；缺省内置常见 12 节）
    { index: 1, start: '08:00', end: '08:45' }, …
  ],
  weekOffset: 0                // 手动偏移（个别学校周一起始差异兜底）
}
```

### 3.3 设置 settings（复用番茄AI 键结构）
```js
{ themeMode: 'light' | 'dark', firstDayOfWeek: 1, showWeekend: true, defaultColor: … }
```

### 3.4 存储策略
- 键白名单：`courses` / `schedule_meta` / `settings`（Rust 侧同步）；
- 完整复用：信封 `{v, savedAt, data}` 双写、chooseSide 取新、写队列、3s/5s 超时、启动预热；
- 纯函数层（周次判定、冲突检测、导出整理）全部独立成 `src/utils/schedule.js` 便于测试。

## 四、用户界面流程

### 4.1 主流程（打开即用，无需任何前置步骤）
```
启动 → 周课表（自动定位当前周，本周高亮）
 ├─ 点课程卡片 → 课程详情/编辑/删除
 ├─ 空白格长按（或右下 + 悬浮钮）→ 新建课程向导
 │    第 1 步：名称/地点/教师（快输）
 │    第 2 步：星期 + 起止节次（网格点选，直观）
 │    第 3 步：周次规则（每周/单周/双周/自定义，默认每周）
 │    第 4 步：颜色（色盘）→ 保存
 ├─ 顶部周次条：‹ 第 12 周 ›  /  回到本周
 └─ 设置入口（右上角）：学期起始日、节次时间、暗色主题、备份/恢复
```

### 4.2 网格渲染规则
- 周一至周日 7 列（可隐藏周末），行 = 当天最大节次数；
- 课程块按 startSection/endSection 纵向合并，星期列定位，颜色区分课程；
- 非"本周上课"的课程（单双周/自定义周次不命中）灰显或隐藏（设置可切）；
- 今天列高亮 + 当前节次时间指示线（P2）。

## 五、技术实现路径

| 层 | 选型 | 说明 |
|---|---|---|
| 前端 | Vue 3 setup + Vite | 与番茄AI 一致，组件可整体移植 |
| UI | NaiveUI（按需自动导入） | 表单/弹窗/开关直接复用 |
| 存储 | localforage + Tauri 文件镜像双写 | **移植番茄AI 的 storage.js 核心**（含预热/自检），键白名单按 3.4 |
| 运行时 | Tauri 2（Android APK） | 复用 .build 便携工具链与打包流水线文档 |
| 测试 | vite build --ssr 打包 + node 断言 | 纯函数（周次判定/冲突/导出）+ 双写核心测试移植 |
| 设计 | 番茄AI 设计令牌 v2（CSS 变量）+ 图标风格 | 深色模式、圆角、动效 token 直接沿用 |

复用最大化：storage.js / utils/date.js / base.css / 图标素材 / 打包脚本 / 测试框架 ≈ 直接拷贝改造；
新增代码集中在：周视图网格组件、课程表单、周次计算纯函数。
