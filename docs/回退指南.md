# 回退指南：回到"路线A之前"的形式

> 目的：如果专注页卡死问题经加固后仍无法接受，可按本指南回退代码形态。
> **数据安全承诺：回退只动代码文件，不动 IndexedDB 数据库，任务/番茄记录/设置全部保留。**

## 〇、回退前必做（数据安全第一）

1. 打开应用 → 设置 → 数据管理 → **导出备份**，把 JSON 文件存到项目外（如桌面）；
2. 确认备份文件可打开、包含 `tasks` 与 `pomodoroRecords` 字段。

## 一、什么是"路线A之前"的形态

即原 8 阶段主流程交付的版本：番茄钟**无休息自动切换、无任务绑定**；任务页无已消耗计数徽标与概览行；无备份导出/导入、无会话事件；AI 页无服务商预设下拉与复盘复制；设置页无休息时长与通知/音效开关。

## 三、数据兼容性说明（回退不会丢数据）

- 数据库仍是同一个 `tomato-ai` IndexedDB 库，**回退不删库**；
- 旧代码读取任务时忽略 `consumedPomodoros` 等新字段（无害）；
- 旧代码的设置读取用"默认值 + 合并"方式，多余设置项会被保留但不再生效；
- `pomodoro_events` 表回退后不再写入/读取（数据滞留无害，可忽略）。

## 四、回退后的注意事项

1. 备份导出/导入功能会随回退**消失**——若之后想恢复该能力，找我加回；
2. 番茄记录结构不变，统计页仍可读历史数据；
3. 若回退后仍想用新功能，可用方式 A 的 `checkpoint-before-rollback` 提交直接切回；
4. 建议回退后也保留 git 提交记录（两个检查点都在），进退自如。

## 五、强烈建议（先试这个，通常不用回退）

专注页卡死大概率与你的嵌入式浏览器渲染压力有关。先按下面的"低负载模式"使用：

1. 日常使用**优先 4173**（双击 `启动网页-生产版.bat`），开发才用 5173；
2. 使用前**重启浏览器**（彻底关闭再打开），消除旧页面会话残留；
3. 完成提醒三开关建议先只开"提示音"，**关闭"浏览器通知"**（部分 WebView 的权限请求会卡住页面）；
4. 若仍卡，把番茄时长保持默认 25 分钟，避免 1 分钟快速循环触发高频副作用。
