> 状态：规划完成，进入 P0 初始版本开发
> 形态：在现有番茄AI 应用内新增一级功能（非独立应用），与专注/任务/统计/AI/设置共存

## 一、功能描述

### 1.1 目标
在番茄AI 中内置一个极简课程表：周课表视图 + 课程管理（含单双周/自定义周次规则），
延续应用哲学（零登录、零广告、本地优先），并沉淀为后续"课程时段 × 番茄专注"联动的数据基础。

### 1.2 功能清单（P0 初始版）
| 编号 | 功能 | 说明 |
|---|---|---|
| F1 | 周课表视图 | 周一~周日 7 列 × 节次行网格；课程卡片按星期+节次定位、按颜色区分 |
| F2 | 周次导航 | 顶部 `‹ 第 N 周 ›`，初始自动定位**当前周**（按学期起始日计算）；"今天"一键回位 |
| F3 | 单双周/自定义周次 | 课程周次规则：每周 / 单周 / 双周 / 自定义周次列表；非本周课程自动隐藏 |
| F4 | 课程管理 | 添加/编辑/删除；字段：名称、地点、教师、星期、起止节次、周次规则、颜色 |
| F5 | 学期设置 | 学期起始日（第 1 周锚点）、总周数；影响当前周定位与过滤 |
| F6 | 本地持久化 | 新键 courses / schedule_meta，复用双写加固（信封/比较取新/预热/自检） |

### 1.3 明确不做（P1+ 候补）
节次时间表自定义、隐藏周末、冲突检测、课程备注导出、与任务/专注联动、系统日历跳转、JSON 备份。

## 二、技术实现路径

| 层 | 做法 |
|---|---|
| 路由/导航 | 新增 `/schedule` 路由 + 底部导航第 3 位「课表」（图标新绘制 grid 风格，走现有蒙版体系） |
| 数据 | 复用 `storage.js` 双写核心：新增 `courses` / `schedule_meta` 键（JS FS_KEYS + Rust 白名单同步） |
| 状态 | `useSchedule` 单例 composable（对齐 useTasks 模式：共享 ensureLoaded、写透式持久化） |
| 纯逻辑 | `utils/schedule.js`：周次计算、周次规则命中、缺省节次表（12 节默认时间）——全部纯函数可测 |
| UI | ScheduleView.vue：CSS 网格布局课程表 + n-modal 表单/详情；色板与设计令牌 v2 对齐 |
| 图标 | 程序绘制 grid_view 蒙版 PNG（描边/填充两态），无新素材依赖 |

### 数据流（简）
```
ScheduleView ── CRUD ──▶ useSchedule(内存单例) ──▶ storage.js dual.write
                                                      ├─ IndexedDB(courses/schedule_meta)
                                                      └─ 文件镜像(courses/schedule_meta)
启动: ensureLoaded ◀── dual.read（信封比较取新 + 自动修复）
周次显示: 当前日期 + schedule_meta.semesterStart ──▶ weekNumberFor() ──▶ 网格过滤 courseInWeek()
```

### 数据结构
```js
// courses
{ id, name, location:'', teacher:'', dayOfWeek:1..7, startSection, endSection,
  weekRule:{ type:'every'|'odd'|'even'|'custom', weeks:[] }, color:'#…', createdAt }
// schedule_meta
{ semesterStart:'YYYY-MM-DD'(周一), totalWeeks:20 }
// 颜色：预置 8 色盘（番茄红系 + 中性辅助色），自动分配、可改
```

  ① 任务 🍅 计数不增加；② `emit('pomodoro:completed')` 不执行、统计页不自动刷新。
- 修复：`useTasks()` 返回对象补齐该方法（API 完整性）；onComplete 调整为先广播再计数（联动异常不阻断统计）。
- 防回归：测试新增 `useTasks() 暴露 incrementTaskPomodoros` 断言。

**导入增强**
1. `parseTableGrid`：完整处理 **rowspan/colspan**（合并单元格文本填充全部覆盖格位，
   等宽网格归一化）——同时修复列式表遇合并单元格的错位；
2. `parseHtmlMatrix`：**矩阵式课表解析**（星期为列头、节次为行头；`@地点`/教师/周次启发式提取；
   **连堂（rowspan 跨行）自动合并**为单门课程的节次范围）；`parseHtmlCourseTable` 列式优先、矩阵回退；

**测试**：83/83 通过（新增 7 项：网格还原、矩阵单元格启发式、矩阵解析连堂合并、列式/矩阵互不误判、去重边界、补色、API 防回归）。

## 十、v0.2.4 记录（beangle EAMS 教务专属适配——基于真实页面）

用户提供湖南第一师范教务（beangle EAMS，courseTableForStd）保存的 HTML 后定位到关键结构：
**页面内嵌 JS 含结构化课程数据**——每门课一个
`new TaskActivity(教师IDs, 教师名, 课号, "课程名", 房间ID, "地点", "周次位图(53位)", ...)` 调用，
随后 `index = 星期*unitCount + 节次`（0 基，unitCount=14，节次行含"中午一节/中午二节"两个非上课行）。
周次位图与页面标题完全吻合（如毛概 `0111111111011111100...` = "1-9周 11-16周"），比表格文本解析精确。

实现（`parseEamsScript`，置于解析链最优先：EAMS → 列式 → 矩阵式）：
1. 按 `var teachers = [...]` 块切分，提取教师名与 TaskActivity 参数（手写括号/引号感知的参数切分，
   纯字符串+正则处理，不使用 DOMParser）；
2. 周次位图 → 周次集合 → `weeksToRule` 自动归类 每周/单周/双周/自定义；
3. **停课活动过滤**（地点="停课" 或 房间ID=-1）；
4. **中午行映射**：行头标签序列中"中午X节"不占节次号（第五节→第 5 节……第十二节→第 12 节），与教务显示对齐；
5. **连堂合并**：同一活动的多条 `index` 行合并为节次范围；
6. **同槽不同周次合并**：同名同天同节次的多个活动（毛概的探究式/红墙/游学路实践周）合并为一条，
   周次取并集、地点取覆盖周最多者，避免课表格子里堆叠 4 个色块。

**测试**：90/90 通过（新增 7 项：字段映射、中午行对齐、位图多区间周次、停课跳过、同槽合并、weeksToRule 归类、解析链路由）。

**已知边界**：教务页不含"学期第 1 周日期"，导入后需在 ⚙ 手动设置学期起始日（总周数按教务为 20 周）。
