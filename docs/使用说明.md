# 番茄AI · 个人自用说明

> 极简 AI 时间管理工具：番茄钟 + 任务清单 + 统计 + AI 助手。
> 零广告、零社区、零登录；所有数据只存在你自己的浏览器里。

## 一、启动方式

```bash
cd D:\program\zcode\tomato-ai
npm run dev        # 开发模式 → 浏览器打开 http://localhost:5173
```

或双击项目根目录的 `启动网页.bat`（自动启动服务器并打开浏览器）。
**不要双击任何 index.html 文件**（框架原因打不开，见文末常见问题）。

## 二、日常使用流程

1. **任务页**：添加任务（可填预估番茄数，如"写周报，约 4 个番茄"）；
2. **专注页**：选择任务绑定（可选）→ 选时长 → 开始专注；
3. 番茄完成 → 自动进入休息（每 4 个番茄一次长休息，可在设置调整）；
4. **统计页**：查看今日/本周/累计数据与近 7 天趋势；
5. **AI 助手页**：大任务让 AI 拆解 → 一键导入任务列表；周复盘看总结与建议。

## 三、配置 AI（可选，不配也能用全部功能）

模拟模式（默认开启）下 AI 返回示例数据，可完整体验界面。

接入真实模型：

1. 设置 → AI 配置 → 选择服务商（自动填入地址和模型）；
2. 填入你的 API Key（输入框为掩码，点眼睛可见）；
3. **关闭"模拟模式"** → 点"测试连接"验证；
4. 回 AI 助手页使用。

各服务商 Key 获取：

| 服务商 | 获取位置 | 模型填写 |
| --- | --- | --- |
| DeepSeek | platform.deepseek.com 申请并充值 | `deepseek-chat`（默认已填） |
| 豆包（火山方舟） | 火山方舟控制台创建"推理接入点" | 填接入点 ID（形如 `ep-xxx`） |
| 通义千问 | 阿里云百炼控制台申请 API-KEY | `qwen-plus`（默认已填） |

> 🔒 安全：Key 只保存在本机浏览器，不会上传；备份文件里**不含 Key**；
> AI 调用时仅把当前任务文本与统计摘要发给模型，不保存你的隐私。

## 四、备份数据（重要，建议每周一次）

浏览器缓存可能因清理站点数据、重装系统而丢失，请定期备份：

1. 设置 → 数据管理 → **导出备份** → 得到一个 JSON 文件（含任务、番茄记录、会话事件、设置）；
2. 需要恢复时 → **导入备份** → 覆盖恢复全部数据；
3. 清空数据 → 一键删除任务/记录/事件/设置（不可恢复，会二次确认）。

## 五、已知限制

| 限制 | 说明 |
| --- | --- |
| 手机锁屏/后台计时暂停 | 网页与 WebView 打包版在锁屏后 JS 定时器被挂起；回到前台时间自动校准、记录不丢，但"完成提醒"会延迟到回前台才触发 |
| 浏览器通知 | 仅桌面浏览器支持（需授权）；安卓 WebView 不支持，自动跳过 |
| 数据存放位置 | 浏览器 IndexedDB——清理浏览器数据、卸载浏览器会丢失，**务必用备份** |
| 模拟模式 | 无 Key 时 AI 返回示例数据，仅用于体验界面 |

## 六、常见问题

| 问题 | 解决 |
| --- | --- |
| 双击 index.html 打不开/白屏 | 正常现象，必须通过 `npm run dev` 后用 `http://localhost:5173` 访问 |
| 番茄完成了但任务计数没变 | 检查专注页是否绑定了该任务（绑定下拉框） |
| 统计页没有数据 | 确认完成过番茄（不是放弃）；数据在 IndexedDB，切页自动刷新 |
| 想完全重置 | 设置 → 数据管理 → 清空本地数据（或先导出备份再清空） |
| 手机锁屏后回来时间不对 | 属已知限制，回到前台会自动校准；如需后台计时请用原生版（见打包指南优化方向） |
